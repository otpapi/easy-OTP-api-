1. Getting Started

Easy OTP allows you to dispatch secure 6-digit session validation codes seamlessly via WhatsApp API channels and GMail SMTP servers with zero setup costs.

POST

/api/send-otp

Transmit an authorization OTP code to any Indian number instantly.

cURL NodeJS Python 
curl -X POST https://easyotpapi.online/api \
  -d "userId=3f70ce48-c778-4c75-a786-b36af6281ec6" \
  -d "number=919876543210" \
  -d "otp=123456"
